A set of commands to generate and manage experiments experiments: run, show, diff, apply, branch, remove, push, pull, list, and clean. Requires that Git is being used to version the project. Synopsis dvc exp { show | apply | diff | run | branch | list | push | pull | remove | clean } Description dvc exp subcommands provide specialized ways to create and manage data science/ machine learning experiments. See Experiment Management for more info. Note that DVC assumes that experiments are deterministic (see Avoiding unexpected behavior). Options -h, --help - prints the usage/help message, and exit. -q, --quiet - do not write anything to standard output. -v, --verbose - displays detailed tracing information. doctor exp apply Content Synopsis Description Options 🐛 Found an issue?
