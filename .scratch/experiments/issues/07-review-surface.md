# 07 — The review surface: a recorded result nobody has read

## Question

An experiment closes as soon as its record is complete — the numbers, whether they met the frozen
reference, what the run covered — with no signature from the operator (`.4`). Interpretation is optional
and lives outside the ticket: the record carries `reading: none yet` until the operator says what the
result means, and only then does it feed an idea or a work ticket (`.3`, `.4`).

Nothing sweeps for results still carrying that line. The development domain has a review surface — the
drain reports the range of Main it did not write, and a human reads the summary — and this domain has
none.

So what makes an unread result visible, and to whom? A sweep listing closed experiment tickets whose
`reading:` is still empty, a section of some report, a line in a map's Decisions-so-far, or nothing at
all — on the argument that a result nobody wants to read is itself an answer? And if there is a sweep,
does anything act on it, or does it only put the list in front of the operator?

Depends on the experiment kind's name in the store, because a sweep is a query over it (`.5`).
