# 05 — The experiment kind, and what keeps the drain off it

## Question

What is an experiment ticket in the store? The drain refuses `decision` by type and takes everything else
that carries the gate label, so an experiment ticket that is not `decision` would be drained as work — and an
experiment is not work that merges into Main.

A custom type registered in the store's own configuration and refused by the drain's rules, or an existing
kind plus a label, and which of those can the store enforce by itself? The answer also fixes what the drain
does with a chain that reaches an experiment issue.
