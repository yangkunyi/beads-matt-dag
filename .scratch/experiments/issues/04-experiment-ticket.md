# 04 — An experiment ticket, and who may work it unattended

## Question

What is an experiment ticket's body — hypothesis, the metric that decides it, the budget, the data pin — and
what may an agent do alone: write the script, run it, record the result? Where is the HITL line: changing the
deciding metric, extending a budget, judging a result nobody expected?

The inquiry domain settled its analogue by making the AFK leg read-only. An experiment differs in kind — the
run *produces* the fact rather than reporting one — so the same question has to be asked again instead of
copied, and its answer is what a run's bookkeeping has to be able to say.
