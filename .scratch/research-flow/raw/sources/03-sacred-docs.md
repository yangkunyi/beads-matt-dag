<h1>Welcome to Sacred’s documentation!<a class="headerlink" href="#welcome-to-sacred-s-documentation" title="Permalink to this headline">¶</a></h1>
<blockquote>
<div><div class="line-block">
<div class="line"><em>Every experiment is sacred</em></div>
<div class="line"><em>Every experiment is great</em></div>
<div class="line"><em>If an experiment is wasted</em></div>
<div class="line"><em>God gets quite irate</em></div>
</div>
</div></blockquote>
<p>Sacred is a tool to configure, organize, log and reproduce computational
experiments. It is designed to introduce only minimal overhead, while
encouraging modularity and configurability of experiments.</p>
<p>The ability to conveniently make experiments configurable is at the heart of
Sacred. If the parameters of an experiment are exposed in this way, it
will help you to:</p>
<blockquote>
<div><ul class="simple">
<li>keep track of all the parameters of your experiment</li>
<li>easily run your experiment for different settings</li>
<li>save configurations for individual runs in files or a database</li>
<li>reproduce your results</li>
</ul>
</div></blockquote>
<p>In Sacred we achieve this through the following main mechanisms:</p>
<blockquote>
<div><ol class="arabic simple">
<li><em>Config Scopes</em> are functions with a <code class="docutils literal notranslate"><span class="pre">&#64;ex.config</span></code> decorator, that turn
all local variables into configuration entries. This helps to set up your
configuration really easily.</li>
<li>Those entries can then be used in <em>captured functions</em> via <em>dependency
injection</em>. That way the system takes care of passing parameters around
for you, which makes using your config values really easy.</li>
<li>The <em>command-line interface</em> can be used to change the parameters, which
makes it really easy to run your experiment with modified parameters.</li>
<li>Observers log every information about your experiment and the
configuration you used, and saves them for example to a Database.
This helps to keep track of all your experiments.</li>
<li>Automatic seeding helps controlling the randomness in your experiments,
such that they stay reproducible.</li>
</ol>
</div></blockquote>
</div>
