 Introduction
 Introduction
 Learn what Conductor is and where to start in the docs
 Conductor lets you run Claude Code, Codex, Cursor, and OpenCode in parallel.

 Each task gets its own workspace, branch, files, terminal, diff, and review path.

 When the work is ready, Conductor helps you review the diff, open a pull request, merge, and archive the workspace.
