## W&B Launch

- [W&B Launch](https://docs.wandb.ai/platform/launch.md): Scale and manage ML workloads with W&B Launch by configuring jobs, queues, and agents on your compute infrastructure.
- [Tutorial: W&B Launch basics](https://docs.wandb.ai/platform/launch/walkthrough.md): Follow this getting started tutorial for W&B Launch covering jobs, queues, agents, and running ML workloads.
- [Launch terms and concepts](https://docs.wandb.ai/platform/launch/launch-terminology.md): Learn key W&B Launch concepts including jobs, queues, target resources, agents, and agent environments.

### Set up Launch

- [Set up Launch](https://docs.wandb.ai/platform/launch/set-up-launch.md): Set up W&B Launch by configuring a queue and deploying an agent to submit jobs to your compute infrastructure.
- [Configure launch queue](https://docs.wandb.ai/platform/launch/setup-queue-advanced.md): Configure advanced launch queue options including queue config templates with defaults, minimums, and maximums.
- [Set up launch agent](https://docs.wandb.ai/platform/launch/setup-agent-advanced.md): Configure advanced agent options for W&B Launch including Docker and Kaniko builders and container registry settings.

#### Configure compute resources

- [Tutorial: Set up W&B Launch with Docker](https://docs.wandb.ai/platform/launch/setup-launch-docker.md): Set up W&B Launch to run ML jobs using Docker on a local machine as both the agent environment and compute target.
- [Tutorial: Set up W&B Launch on Kubernetes](https://docs.wandb.ai/platform/launch/setup-launch-kubernetes.md): Set up W&B Launch on a Kubernetes cluster using Helm charts, Kaniko image building, and Kubernetes job specs.
- [Tutorial: Set up W&B Launch on SageMaker](https://docs.wandb.ai/platform/launch/setup-launch-sagemaker.md): Configure W&B Launch to submit training jobs to Amazon SageMaker with ECR, S3, and IAM setup instructions.
- [Tutorial: Set up W&B Launch on Vertex AI](https://docs.wandb.ai/platform/launch/setup-vertex.md): Set up W&B Launch on Google Cloud Vertex AI using CustomJob specs and Artifact Registry for ML workloads.

### Create and deploy jobs

- [Create and deploy jobs](https://docs.wandb.ai/platform/launch/create-and-deploy-jobs.md): Create and deploy machine learning jobs using W&B Launch to run workloads on your target compute resources.
- [Create a launch job](https://docs.wandb.ai/platform/launch/create-launch-job.md): Create W&B Launch jobs from Git repositories, code artifacts, or Docker images using the wandb launch command.
- [Add job to queue](https://docs.wandb.ai/platform/launch/add-job-to-queue.md): Add launch jobs to a W&B Launch queue using the App UI or CLI to schedule ML workloads on target resources.
- [Manage job inputs](https://docs.wandb.ai/platform/launch/job-inputs.md): Programmatically manage and configure job inputs such as hyperparameters and file-based configs for W&B Launch jobs.
- [View launch jobs](https://docs.wandb.ai/platform/launch/launch-view-jobs.md): View launch job details, list available jobs, and check job statuses in the W&B App and CLI.

### Advanced

- [Create sweeps with W&B Launch](https://docs.wandb.ai/platform/launch/sweeps-on-launch.md): Discover how to automate hyperparamter sweeps on launch.
- [Monitor launch queue](https://docs.wandb.ai/platform/launch/launch-queue-observability.md): Monitor launch queue workloads with an interactive dashboard to spot inefficient jobs and analyze resource usage.
